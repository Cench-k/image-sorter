# Smart Image Sorter

AI 이미지 생성 도구(Google Flow 등)로 만든 이미지를 **프롬프트 TXT의 번호 순서대로 자동 매칭**하고, `01_scene.jpeg`, `02_scene.jpeg` … 형식으로 파일명을 일괄 변경해 주는 로컬 웹앱입니다.

- 이미지 **내용 자체**를 보고 어느 프롬프트로 만든 그림인지 판단 (CLIP)
- 파일명 캡션(`Man_looking_at_wife_2026...jpeg`)도 보조 단서로 활용
- 같은 프롬프트로 여러 장 뽑은 경우 `38_1`, `38_2` 로 묶음
- 애매한 이미지는 **👀 확인 필요**로 표시, 드롭다운으로 번호를 직접 바꿀 수 있음
- 파일명 변경 후 **되돌리기(Undo)** 지원
- API 키 불필요, 인터넷 연결은 최초 설치 때만 필요 (이미지는 외부로 전송되지 않음)

## 요구 사항

- Windows 10/11
- [Python 3.10 이상](https://www.python.org/downloads/) — 설치할 때 **"Add python.exe to PATH"** 체크
- 디스크 여유 공간 약 3GB (PyTorch + CLIP 모델)
- GPU 필요 없음 (CPU로 동작)

## 설치 및 실행

1. 이 페이지 위쪽 **Code → Download ZIP** 으로 받아서 압축 풀기 (또는 `git clone`)
2. 폴더 안의 **`run.bat`** 더블클릭

처음 실행하면 필요한 패키지를 자동으로 설치하고(몇 분), 첫 분석 때 CLIP 모델(약 1.7GB)을 내려받습니다. 두 번째부터는 바로 실행됩니다. 브라우저가 자동으로 `http://localhost:7860` 을 엽니다.

## 사용법

1. **Step 1** — 프롬프트 TXT 파일을 드래그하거나 경로를 입력
2. **Step 2** — 이미지가 들어있는 폴더 경로 입력 → **이미지 내용 분석 및 매칭 시작**
3. 결과 확인
   - **👀 확인 필요** 탭에서 애매한 것만 골라 썸네일로 확인
   - 틀린 게 있으면 이미지 옆 드롭다운에서 번호 변경 (AI 추천 후보가 위에 표시됨)
   - 필요 없는 이미지는 "미분류로 빼기" → 파일명을 바꾸지 않음
4. **파일명 일괄 변경 실행** — 잘못 바꿨다면 우측 상단 **변경 되돌리기**

### TXT 형식

번호로 시작하는 줄마다 한 항목으로 인식합니다. 번호가 없으면 빈 줄로 구분된 문단 순서대로 번호를 매깁니다.

```
1. @gopdan, a young woman ... — Two-shot of the young man and woman at a spilled market stall, ...
2. @anseongdaek, a middle-aged woman ... — Over-the-shoulder shot of the older woman ...
```

`—` 가 있으면 그 뒤를 장면 설명으로 쓰고(여러 프롬프트에 반복되는 화풍 문구 등은 자동 제외), 앞쪽 `@인물, 외모 설명`은 인물 옷차림 비교에 따로 씁니다.

## 동작 원리

1. 각 이미지와 각 프롬프트의 장면 설명을 CLIP(`openai/clip-vit-large-patch14`)으로 비교
2. 프롬프트의 `@인물, 외모 설명` 부분으로 인물 옷차림도 비교 (비슷한 장면에 다른 인물이 나오는 경우 구분)
3. 파일명 캡션과 프롬프트의 단어 유사도(TF-IDF)를 보조 점수로 더함
4. 번호마다 "이미지 수 ÷ 프롬프트 수"장씩 받도록 헝가리안 알고리즘으로 전체 최적 배정
   (프롬프트당 2장씩 뽑았으면 2장씩, 기대보다 많이 몰리는 번호엔 페널티)
5. 1순위와 2순위 점수 차이가 작으면 "확인 필요"로 표시

실제 데이터(프롬프트 49개)로 확인한 정확도: 1장씩 51장 **51/51**, 2장씩 98장 **98/98**

이미지 임베딩은 파일 내용 기준으로 `.embed_cache/` 에 저장되어, 같은 이미지를 다시 분석할 때는 몇 초면 끝납니다.

## 한계

- CLIP은 **영어 프롬프트** 기준으로 학습된 모델이라, 한국어 프롬프트는 정확도가 크게 떨어집니다.
- 서로 매우 비슷한 장면(같은 인물, 같은 장소, 비슷한 구도)이 많으면 헷갈릴 수 있으니 "확인 필요" 항목은 꼭 눈으로 확인하세요.

## 제거

- 프로젝트 폴더 삭제
